# speak-back s0 — DESIGN

GENESIS-II arc1 · inverse of speak-in · field state → word/utterance.

## Goal

Read the semantic channels the field already carries → collapse to a token.
speak-in: word → excite semantic channel (input.rs Tone/Gaussian/Stroke).
speak-back: field state → probe channels → decode → token.

## Input model (from field-unified + v2-input-excite)

- One field = one Slice (W×H hypervector, d = W·H).
- Store = N×d resident; probe() = attention over slots 2.., cosine, top-k,
  0.47 ms/frame @ N=4096, d=16K (store.rs bit-exact rewrite).
- Semantic anchors = seeded atoms (atoms.rs): unit-norm, deterministic,
  near-orthogonal.
- speak-in writes (CORRECTED, s1 audit): Op::Excite = **Gaussian strike**
  (σ=2, r=8) at spatial (x,y) — NOT dense-atom addition. Sealed speak-in
  (cosmo-speak@c5ef614e): word → fnv1a+mix64 → 3 channels of C64 →
  8×8 grid cell center → Gaussian excite, amp signature ∈ [0.4,1.0].
  atoms live in store slots 2.. only (Op::SeedAtom), never bound to plane.
  ∴ dense-atom cosine (head A) ≈ 0 vs real speak-in output → head A valid
  only for synthetic superposition model. TRUE inverse = head C below.

## Channels we read

1. **Plane semantic channels** — atoms bound into the wave plane itself.
   - read slot 0 (cur) unwrapped as d-vector.
   - correlate against anchor lexicon → similarity map.
2. **Store semantic slots** — atoms parked in slots 2..N.
   - reuse existing store.probe(key_atom, top_k).
3. **Bound compositions** — multi-word utterances stored as
   bind(atom_a, atom_b) in a slot.
   - read via unbind(correlation) or direct probe against composed anchors.

§ Priority: s0 proves (1). (2) is free because probe() exists. (3) deferred.

## Probe schedule

- **Hot cadence** (120 fps): read plane slot 0 only, no store scan.
  - Budget: ≤ 0.5 ms for plane decode (matches store.probe perf).
- **Warm cadence** (every 4–8 frames): probe store slots 2.. for sustained
  concepts / working memory.
- **Cold cadence** (off-frame): journal replay, learned decoder update.

Determinism: schedule is a function of step_index → no clock, no rand.

## Decoding: two heads

### A. Nearest-semantic-anchor (s0)

- Lexicon L = {word_i → atom_i} deterministic seeded atoms.
- Given field state s, score_i = cosine(s, atom_i).
- Collapse: argmax_i score_i, threshold τ.
- Pros: zero learn, bit-exact, O(|L|·d) — |L| small (< 256 for boot lexicon).
- Cons: cannot resolve superpositions beyond linear separation; no grammar.

### B. Learned decoder head (mu-v0)

- A small linear or MLP head h_θ: s → logits over vocabulary.
- Trained from (field_state, utterance) pairs generated by speak-in + human
  annotation, or self-supervised from paired speak-in/speak-back traces.
- Initial θ = identity to nearest-anchor → cold-start deterministic.
- Pros: resolves bundled channels, context, grammar.
- Cons: needs data; must stay within 0.5 ms/frame on ANE/Metal.

§ s0 implements A only. B = open question / next lane.

### C. Cell-energy readout (s1 — TRUE inverse of sealed speak-in)

FIX (kimi audit F1, 2026-08-01): mirror prime corrected to the field crate's
actual (non-standard) FNV prime `0x0000_0100_0000_01b3`; previously the
standard `0x1000001b3` → decoded WRONG channels vs real speak-in (gates were
self-consistent only). Parity now pinned vs field truth in
`prime_parity_vs_field_truth` (cell_gate.rs).

- 觀: plane → 64 cell energies (Σv² per 8×8 cell, row-major f64, O(W·H)).
- word signature = expected energy pattern: amp² at its word_channels
  (mirror of speak.rs constants: CHANNELS=64, GRID=8, WORD_CHANNELS=3,
  AMP_MIN=0.4).
- score = cosine(signature, energies) over C64 → argmax, τ, tie-break id.
- Cost: O(W·H + |L|·64) ≪ head A's O(|L|·d). No ML, exact mirror, decode
  survives uniform damping (cosine scale-invariant — gated).
- src/cell_decode.rs · tests/cell_gate.rs (7 gates: per-word blob decode,
  stronger-wins, top-2, bit-identical rebuild, damped decode, empty→None,
  signature↔channels mirror).
- Gates use synth_speak = Gaussian-blob emulation of real Op::Excite form.
  Integration vs real World::apply = UNVERIFIED (field pkg not on main;
  next: run in cosmo-speak worktree).

## Latency budget

| Stage | Budget | Notes |
|-------|--------|-------|
| plane read (slot 0) | 0.05 ms | already resident |
| cosine scan anchors | 0.3 ms | |L|=256, d=16K, SIMD f32 |
| top-k + threshold | 0.05 ms | k ≤ 8 |
| token emit | 0.05 ms | string table |
| **total per frame** | **≤ 0.45 ms** | leaves 7.88 ms frame headroom @ 120 Hz |

Note (s1 audit): headroom is vs the 8.33 ms frame alone; existing tick work
(bind + probe ≈ 4.15 ms) also draws from it → real headroom ≈ 3.7 ms.
Head C replaces the 0.3 ms cosine scan with O(W·H) energy pass + |L|·64
correlation → cheaper at boot-lexicon sizes.

Store probe reused for slots 2..: 0.47 ms/frame measured; amortized every
4–8 frames → ~0.06–0.12 ms/frame average.

## Determinism

- Lexicon atoms seeded from world seed → reproducible across boots.
- Cosine uses f64 accumulators, fixed iteration order (NOTE: loop structure
  differs from ops::similarity — bit-exactness holds within this crate,
  cross-engine bit-parity not claimed).
- Top-k tie-break: lower word-id first.
- Threshold τ is a fixed f32 constant; hysteresis optional (sticky winner).
- Output token is a function of field state + step_index only.

## Architecture sketch

```
field state (slot 0 / store slot k)
        │
        ▼
[plane read] ──► Slice s
        │
        ▼
[anchor bank] ──► {atom_fire, atom_water, ...}
        │
        ▼
[cosine scan] ──► scores[|L|]
        │
        ▼
[top-k + τ] ──► candidates
        │
        ▼
[token table] ──► "fire"
```
